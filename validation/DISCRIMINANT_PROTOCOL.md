# Discriminant test protocol (written 2026-10-05, BEFORE any variant was scored)

Config: frozen method of record (tag `method-of-record-2026-10-05`). Nothing is tuned after this.
Variants: generated by `validation/degrade_ssp.py` from the strong FleetTrack SSP (deterministic).

| Variant | Kind | What changes | Quality by construction |
|---|---|---|---|
| strong | - | FleetTrack as authored | highest |
| partial | feature-aligned | every 3rd statement deleted; kept text cut to first sentence, artefacts generalised | middle |
| broken | feature-aligned | only every 3rd statement kept, each "The system addresses this requirement."; set-params removed | lowest |
| vague_padded | feature-independent | same statements; text = generic padding >= original length + 2 decoy file names | no better than partial |
| swapped | feature-independent | same statements; real implementation texts rotated onto a different control (gap texts stay) | no better than partial (text describes the wrong control) |

Controls are never removed, so Stage 3 pairs are identical across variants (checked structurally).
Realization is compared over FleetTrack's 17 SSP controls (mean of control-level Realization).

## Hypotheses and pass criteria (fixed now)
- **H1 (aligned degradation)** - mean Realization strictly decreasing: strong > partial > broken.
  Per-control order violations are reported, not pass/fail. *Prediction: PASS* - but weak evidence,
  because the degradations target the scorer's own features.
- **H2 (Alignment independence)** - every pair's Alignment identical across all five variants
  (max abs difference <= 1e-6). *Prediction: PASS* - Alignment reads clause + catalog only.
- **H3 (padding resistance)** - mean Realization(vague_padded) <= mean Realization(partial).
  *Prediction: likely FAIL* - padding fills the specificity feature and decoy files hit the artefact feature.
- **H4 (wrong-mechanism detection)** - mean Realization(swapped) <= mean Realization(partial).
  *Prediction: likely FAIL* - Maturity reads prose features only and never checks the text against
  the control it is attached to (decision 3, 2026-07-23: heuristic shallowness accepted).

All four results are reported whatever they show. A FAIL on H3/H4 is a measured limitation of the
Realization scorer, not a reason to change the frozen config.
