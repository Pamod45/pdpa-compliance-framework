## The organization's implementation of this control (from its System Security Plan)
- si-18_smt: Driver and vehicle identity records (name, contact, employee ID, vehicle registration, assignment) are correctable via PUT /drivers/{id} and PUT /vehicles/{id} (app/routers/drivers.py, app/routers/vehicles.py), each RBAC-scoped to the Fleet Manager role and the record's own company. No automated data-quality check (e.g. flagging stale contact details) was built - correction is manual, on request, via these endpoints. Deliberately anchored to identity data, not the raw GPS telemetry stream, per the scope.md coverage-table note that accuracy obligations don't naturally attach to a location stream.
